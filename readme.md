# Dulce Aroma — Panadería y Cafetería

## Descripción del proyecto

Dulce Aroma es un sitio web diseñado para una panadería y cafetería que busca mostrar sus productos, publicar sus precios y facilitar el contacto con sus clientes.

El sitio tiene un diseño moderno, con colores inspirados en el café y tonos crema, para transmitir una imagen cálida y agradable. Además, está pensado para que los usuarios puedan navegar desde computadores y dispositivos móviles.

## Objetivo

Crear un sitio web sencillo y adaptable que permita a los clientes conocer los productos de Dulce Aroma, consultar información útil, leer opiniones y acceder a un formulario para realizar pedidos o contactar al negocio.

## Tecnologías utilizadas

- **HTML5:** estructura y contenido de las páginas.
- **CSS3:** estilos, colores, distribución de los elementos y diseño adaptable.

## Estructura del proyecto

- `index.html`: página principal, presentación del negocio, productos, información útil, opiniones y ubicación.
- `contacto.html`: página de contacto con tabla de precios y formulario de pedidos.
- `style.css`: hoja de estilos compartida por ambas páginas.
- `imagen/`: carpeta que contiene las imágenes utilizadas en el sitio web.

## Características del sitio

- Navegación entre las dos páginas.
- Tarjetas para presentar productos y precios.
- Sección de horarios e información útil.
- Opiniones de clientes.
- Mapa para mostrar la ubicación del negocio.
- Tabla de precios.
- Formulario para ingresar datos del cliente y los detalles del pedido.
- Diseño adaptable a dispositivos móviles.

## Funcionamiento del formulario

El formulario permite ingresar el nombre del cliente, correo electrónico, cantidad, producto y detalles del pedido. En esta versión, el formulario es demostrativo: no almacena información en una base de datos ni registra pedidos reales.

## Cómo visualizar el proyecto

1. Descarga o clona el repositorio.
2. Abre la carpeta del proyecto.
3. Abre el archivo `index.html` en un navegador web.
4. Utiliza el menú para navegar entre la página principal y la página de contacto.
